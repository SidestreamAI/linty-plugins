# Linty plugins

The Linty plugin for Claude Code: the Linty MCP server (https://mcp.linty.xyz/mcp) and a skill that tells Claude how to use it.

    claude plugin marketplace add SidestreamAI/linty-plugins
    claude plugin install linty@linty

For other agents, read https://linty.xyz/agents. This repository is a copy of `plugins/marketplace/` in the Linty source. Changes made here are lost at the next copy.
